# Pretty Fly Living  -  Warm & Organic UI prototype

A responsive, multi-page front-end prototype for Pretty Fly Living. Open `index.html` in a modern browser. The interface uses Poppins throughout with a restrained serif display accent, warm neutral surfaces, sage details, responsive navigation and editorial property imagery.

## Included screens
- Home / Our stays
- Stays portfolio with live search, neighbourhood, bedroom, price and sorting filters
- Individual property details with photo viewer, demo availability calendar and booking enquiry
- Why Us
- Things to Do in Nairobi + individual local guide pages
- Property Management with owner enquiry form
- FAQs with guest/property-owner category switch
- Contact page with separate enquiry paths

## Interactions
- Responsive mobile navigation
- Search/filter/sort listings
- Save/favourite property cards
- Property photo viewer modal
- Date validation and booking request handoff to WhatsApp
- FAQ accordions and category switching
- Contact and owner enquiry handoff to WhatsApp or email
- Floating WhatsApp action

## Before production
This is a front-end prototype, not a deployed production booking system. Replace the placeholder WhatsApp number (`254700000000`) and email (`hello@prettyflyliving.com`) with verified business contacts. Connect forms to a secure backend/email provider, persist property content in a database/CMS, implement admin authentication and property CRUD, replace demo prices/photos/content with verified inventory, and integrate a real availability source/channel manager before accepting bookings. The calendar currently demonstrates unavailable-date styling only; it does not represent live inventory. Booking requests are explicitly not confirmed reservations.

Images are loaded from Unsplash and Google Fonts require an internet connection.
